## Overview

shadPS4 Game Manager is a GUI companion for the shadPS4 PS4 emulator that organizes your game library, applies per-game configuration patches, manages save data backups, and monitors compatibility status from the community compatibility database — providing a Launchbox-style frontend for the nascent PS4 emulation ecosystem.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **shadPS4 Game Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Game Library** | Visual grid library interface for shadPS4-compatible game titles |
| **Per-Game Config** | Apply and save per-game configuration patches for compatibility |
| **Save Backup** | Backup and restore individual game save data from emulated storage |
| **Compat Database** | Inline compatibility ratings from the shadPS4 community database |
